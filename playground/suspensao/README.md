# Playground Suspensão — Resposta Visual v0.2

Arquivos revisados para tornar perceptíveis na animação as alterações de:

- massa suspensa;
- rigidez da mola;
- coeficiente de amortecimento.

## Alterações

- Escala visual adaptativa da massa suspensa.
- Realce moderado da resposta próximo à ressonância.
- Exibição da razão de amortecimento.
- Exibição da defasagem da carroceria.
- Exibição da amplitude física da resposta.
- Preservação dos cálculos de `physics.js`.
- Preservação do modo de perda de contato extrema.

## Aplicação

Copie os cinco arquivos para:

`playground/suspensao/`

Depois execute:

```powershell
npm run check
npm run dev
```

No navegador, faça `Ctrl + Shift + R`.
