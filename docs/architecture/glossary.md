| Termo              | Definição                             |
| ------------------ | ------------------------------------- |
| Module             | Organização pedagógica da plataforma  |
| Plugin             | Unidade técnica extensível            |
| Tool Plugin        | Ferramenta reutilizável               |
| Experience Plugin  | Implementa uma experiência pedagógica |
| Integration Plugin | Integra sistemas externos             |
| Core               | Infraestrutura compartilhada          |
| Plugin Manager     | Responsável pelo lifecycle            |
| Manifest           | Metadados do plugin                   |
| Lifecycle          | Estados de execução do plugin         |
| Registry           | Registro de componentes               |
| Event Bus          | Comunicação indireta                  |
| Repository         | Abstração da persistência             |
| Learning Evidence  | Evidência produzida pelo aluno        |
| Capability         | Funcionalidade arquitetural           |
| Boundary           | Limite entre responsabilidades        |
| Contract           | Interface pública                     |
