# D4.5.6F.4.2 — Exception Management UI

Frontend integration over the validated F.4.1 audit model.

The existing exception editor remains authoritative for mutation.

Adds:

- História da exceção beside each current rule;
- read-only current rule summary;
- immutable event timeline;
- before/after field diffs;
- actor ID, timestamp and reason.

No score/grade editing, module_attempt mutation or attempt reopening.
