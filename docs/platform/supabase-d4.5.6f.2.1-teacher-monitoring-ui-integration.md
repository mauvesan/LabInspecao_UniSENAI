# D4.5.6F.2.1 — Teacher Monitoring UI Integration

Frontend integration over the validated F.1 read model.

Changes:

- adds `getApplicationMonitoring(applicationId)` to the existing teacher application service;
- adds `Monitorar alunos` to each application card;
- opens a dedicated read-only monitoring dialog;
- renders summary indicators, search, filters and student table;
- preserves existing application management behavior.

No scorer, enforcement, database or RPC changes.
