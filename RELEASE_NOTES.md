# RELEASE NOTES — v4.1.0

## Objetivo

Transformar a harmonização transversal em uma base de legibilidade didática para todo o LabInspeção.

## Melhorias implementadas

- tokens tipográficos compartilhados;
- corpo de texto e descrições com entrelinha didática;
- títulos de módulo, seção e cartões com hierarquia consistente;
- rótulos, campos, botões e textos auxiliares ampliados;
- alternativas e feedbacks mais confortáveis para leitura;
- tabelas com espaçamento e tipografia mínimos;
- largura de leitura limitada para textos extensos;
- ajustes responsivos para notebook, Full HD e telas estreitas;
- reforço para zoom do navegador e modo de alto contraste.

## Problemas corrigidos

- variação excessiva de tamanho de fontes entre módulos;
- textos auxiliares pequenos demais para uso didático;
- hierarquia desigual entre títulos equivalentes;
- densidade excessiva em cartões, controles e tabelas.

## Incompatibilidades

Nenhuma incompatibilidade funcional conhecida.

## Proteções

A camada não contém seletores para elementos internos de SVG ou canvas e não altera cálculos, simulações, gráficos, animações, quizzes ou persistência.
